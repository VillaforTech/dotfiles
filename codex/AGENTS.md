# Global working agreement

- Treat a request as authorization for reversible, in-scope work inside the selected project: inspect, edit, install project dependencies, test, format, build, manage worktrees, commit, and make task-requested feature pushes or pull requests without repeated confirmation.
- Follow the nearest project `AGENTS.md` for repository commands and invariants. Keep changes inside the selected project unless the request explicitly covers broader host or cross-project work.
- Stop before deleting unique or unbacked data, overwriting broad configuration or history, rotating or revoking credentials, changing sharing or permissions, spending money, publishing or deploying beyond the request, sending unrequested external messages, or materially expanding scope.
- For an explicitly requested destructive or external action, resolve the exact target, inspect current state, and make or verify a recovery point before executing. Ask only when the target or consequence remains ambiguous.
- Never print, commit, transmit, or place credentials in logs. Preserve unrelated dirty work and do not use destructive Git recovery commands unless explicitly authorized.
- Diagnose with evidence, exhaust safe in-scope alternatives, validate proportionally, and report outcomes, tests, and blockers concisely.
